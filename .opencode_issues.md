# Working bug list (temporary, delete when done)

## Candidate A — online_softmax per-batch sink + query tiling
- online_softmax.py: query_chunk path normalizes sink_logits against a
  synthetic B=1 probe, so `[B, 1]` / `[B, 1, 1]` sinks are rejected (or
  mistaken for `[H, 1]`) whenever B > 1 and B != H. The untitled path
  accepts them.
- Repro: `online_softmax_attention(q[2,4,6,8], k, v, query_chunk=3,
  sink_logits=torch.randn(2,1))` -> ValueError.

## Candidate B — exact_test_resolution overflow at tiny p floors
- multi_seed_stats.py: for n_eff beyond the normal float range the p floor
  is subnormal and `alpha / p_min` overflows; `int(math.floor(inf))` raises.
  A large `family_size` times the tiny floor also raises in int->float
  conversion. Both quantities remain well-defined (huge family count / 1.0).
- Repro: `exact_test_resolution(1030)` and with family_size=10**400.
